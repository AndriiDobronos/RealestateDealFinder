# Real Estate Deal Finder

MVP сервісу пошуку інвестиційно привабливих квартир. Поточна версія працює в demo-режимі на локальних оголошеннях і готує UI/алгоритм до підключення офіційного API DIM.RIA.

## Запуск

```bash
npm install
npm run dev
```

## Що вже є

- форма профілю пошуку;
- фільтрація за кімнатами, площею, типом та бюджетом;
- рейтинг на основі ціни за м², районного benchmark, свіжості та перевіреності;
- найкращий збіг та альтернативи;
- пояснення, чому об’єкт отримав рейтинг;
- адаптивна HTML-сторінка;
- окремі модулі даних і scoring, які можна під’єднати до API.

## Наступний крок після API key

Server-side API adapter уже доданий у `api/search.ts`. Для локальної роботи скопіюйте `.env.example` у `.env.local` і заповніть API key. Область і місто визначаються автоматично з `state_ID.json` за назвою міста у профілі пошуку. Для Vercel достатньо додати `DIM_RIA_API_KEY` у Project Settings → Environment Variables. API key не слід зберігати у frontend-коді — тільки в environment variables серверної функції.

Адаптер виконує один пошуковий запит DIM.RIA і максимум 10 запитів деталей оголошень. Це важливо для безкоштовного API-ліміту.

## Захист від помилкової валюти

Перед рейтингуванням об’єкти групуються за валютою, після чого для кожної групи розраховується медіанна ціна за м². Об’єкт відсіюється, якщо його ціна за м² менша за одну сьому медіани цієї самої валютної групи. Це захищає рейтинг від оголошень, де продавець випадково вказав гривневу суму як доларову.

## Деплой на Vercel Hobby

1. Створіть репозиторій Git і завантажте цей проєкт.
2. Імпортуйте репозиторій у Vercel на безкоштовний Hobby-план.
3. У `Project Settings → Environment Variables` додайте `DIM_RIA_API_KEY`, `DIM_RIA_STATE_ID` і `DIM_RIA_CITY_ID` для Production та Preview.
4. Запустіть новий deployment.

Vercel Hobby підходить для особистого MVP. За умовами Vercel цей план призначений для personal/non-commercial use, тому для комерційного сервісу згодом потрібно буде перейти на відповідний платний план або інший провайдер.
